# Novelty Boundary Map

## Crowded Territory

- Generic hierarchical reinforcement learning.
- Option termination alone.
- Safety filters that halt low-level actions.
- Retry-based recovery policies.
- Robust fallback controllers.
- Failure-aware task planning without containment-level diagnosis.

## Claimed Boundary

Hierarchical failure containment models where a failure should be stopped, repaired, or escalated in the control hierarchy before it cascades into subgoal or task-state corruption.

## What Would Falsify The Claim

If failure-aware hierarchical controllers, option termination monitors, robust fallback planners, safety filters, reactive retry policies, causal event graphs, or the v4 containment graph match v5 success, containment, cascade, corruption, damage, false-halt, missed-failure, utility, stress, fixed-risk, and ablation gates under the frozen protocol, the paper should be killed or reframed.

The v5 local benchmark clears the predeclared local gates, so the paper is `STRONG_REVISE`. It remains not submission-ready without external validation.
